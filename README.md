# legal_qa_web
A basic Streamlit Website for Legal QA

## Installation

Pull the repo first, add data to folder data (law_nondup copy 12), add API_KEY in the constant.py

Create venv
```
python -m venv env_name_here
.\env_name_here\Scripts\activate.bat
```

Install requirements
```
pip install -r requirements.txt
```

Run?
```
python bm25.py
streamlit run streamlit.py
```

Remember to remove the api_key afterwards!!!
